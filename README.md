# 🎸 Acoustic Guitar Tuner

A web-based acoustic guitar tuner built with **HTML5**, **CSS3**, and **JavaScript (Web Audio API)**. It uses real-time microphone input and auto-correlation pitch detection to help you tune your 6-string acoustic guitar to standard tuning ($E_2, A_2, D_3, G_3, B_3, E_4$).

## How to Run

1. Clone the repository or download the files.
2. Open `index.html` in any modern browser.
3. Click **Start Tuner** and grant microphone permissions when prompted.
